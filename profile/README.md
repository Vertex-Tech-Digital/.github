## Español

Consultora tecnológica B2B con sede en Santa Cruz de Tenerife (España), especializada en **desarrollo de software a medida**, **integraciones de APIs** y **automatización inteligente con IA** para empresas en España y el mercado DACH.

### Qué construimos
* **Arquitectura Web & Full-Stack:** Aplicaciones empresariales escalables, monorepos modulares y portales corporativos optimizados para rendimiento y Core Web Vitals.
* **Automatización & Motores de IA:** Flujos inteligentes orientados a procesos de negocio, cualificación automatizada de leads e integración multi-modelo (Gemini / OpenRouter) con respaldo determinista.
* **Integraciones & Pasarelas de Pago:** Conexión entre sistemas internos, ERPs/CRMs, facturación automatizada y pasarelas de pago con arquitectura desacoplada (MONEI).

### Stack Tecnológico Principal
* **Frontend:** TypeScript 5.9, React 19, Vite 7, Tailwind CSS v4, Radix UI / Shadcn
* **Backend & Datos:** Node.js 24, Express 5, PostgreSQL (Neon), Drizzle ORM, Upstash
* **Cloud, Calidad & Seguridad:** Vercel, GitHub Actions (CI/CD), ESLint, Husky, suites de testing automatizado y cumplimiento estricto de privacidad (RGPD / PII)

## English

B2B technology consultancy headquartered in Santa Cruz de Tenerife (Spain), specializing in **custom software development**, **API integrations**, and **AI-driven business automation** for companies across Spain and the DACH market.

### What We Build
* **Web & Full-Stack Architecture:** Scalable enterprise applications, modular monorepos, and corporate platforms engineered for high performance and Core Web Vitals.
* **AI Engines & Automation:** Intelligent workflows tailored to business operations, automated lead qualification, and multi-model AI integrations (Gemini / OpenRouter) with deterministic fallbacks.
* **Integrations & Payment Gateways:** Seamless connectivity across internal systems, ERPs/CRMs, automated invoicing, and decoupled payment gateway architectures (MONEI).

### Core Engineering Stack
* **Frontend:** TypeScript 5.9, React 19, Vite 7, Tailwind CSS v4, Radix UI / Shadcn
